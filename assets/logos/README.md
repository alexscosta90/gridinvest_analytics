# Logos das distribuidoras

O dashboard associa os arquivos locais ao CNPJ da coorte em
`dashboard/logos.py`. Os dez logos já existentes são:

| Distribuidora | Arquivo |
| --- | --- |
| Cemig-D | `cemig.png` |
| Enel SP | `enel_sp.png` |
| Neoenergia Coelba | `neoenergia_coelba.png` |
| Copel-Dis | `copel.png` |
| CPFL Paulista | `cpfl_paulista.png` |
| Light | `light.png` |
| Enel CE | `enel_ceara.png` |
| Neoenergia Pernambuco | `neoenergia_pernambuco.png` |
| Celesc-Dis | `celesc.png` |
| Equatorial Goiás | `equatorial_goias.png` |

Para substituir um logo, mantenha o nome de arquivo correspondente. Se um
arquivo faltar, a aplicação exibe o nome da distribuidora sem interromper a
página. Os arquivos atuais foram fornecidos no projeto e não são baixados
automaticamente.
